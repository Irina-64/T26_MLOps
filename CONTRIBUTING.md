# Правила работы с репозиторием

## Ветки
- Ветка `main` защищена. Прямые изменения запрещены, только через Pull Request.
- Для каждой задачи создается отдельная ветка от актуального состояния `main`.

## Коммиты
- Один коммит — одно логическое изменение.
- Формат сообщения: `<тип>: <краткое описание>` (например, `docs: update readme`).
- Запрещено коммитить `.venv`, `.env`, кэши, модели и случайные данные.

## Pull Request и Review
- Каждый PR должен ссылаться на Issue.
- Автор не может одобрять свой собственный PR.
- Требуется минимум 1 одобрение от другого участника.
- Ревьюер должен прочитать весь diff и оставить конкретный комментарий (не просто "LGTM").

## Защита ветки main
Включены правила:
- Merge только через PR.
- Минимум 1 одобрение.
- Обязательный успешный CI (проверка `quality`).
- Запрет force push и удаления ветки.
