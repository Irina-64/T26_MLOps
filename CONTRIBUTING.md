# Как вносить изменения

1. Создайте Issue для задачи и назначьте ответственного.
2. Работайте в своей ветке/форке; не отправляйте изменения напрямую в защищённую `main`.
3. Создайте Pull Request с описанием задачи, решения и проверки.
4. PR должен получить review от участника, который не является автором.
5. Перед слиянием убедитесь, что CI проходит: Ruff и pytest.
6. Связывайте PR с Issue (например, `Closes #1`).

## Локальная проверка
```bash
pip install -e ".[dev]"
ruff check .
pytest
```

## Стиль
- Python 3.12
- Ruff для linting и форматирования
- Небольшие, понятные коммиты
- Не добавляйте секреты, `.env`, ключи, виртуальные окружения, кэши, модели или приватные данные.
