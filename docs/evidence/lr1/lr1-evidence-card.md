# Evidence card ЛР1 (шаблон)

Скопируйте этот файл в `lr1-evidence-card-<ваш-github-login>.md` и заполните.
Совпадающие карточки участников не принимаются.

| Поле | Значение |
|---|---|
| Студент | ФИО, группа, команда, GitHub login |
| Контрольная версия | Ссылка на tag `lr1-v1` и commit SHA |
| Роль | Роль в ЛР1 и зона ответственности |
| Задача | Ссылка на собственный issue с критериями приемки |
| Личный артефакт | PR, review, workflow, README, CONTRIBUTING, CODEOWNERS, ADR или настройка правил |
| Вклад | Что конкретно создано, исправлено или проверено |
| Решение | Выбранный вариант и проверяемая причина выбора |
| Риск | Что могло пойти неверно и как это обнаруживается |
| Результат обучения | Что вы теперь можете повторить самостоятельно |
| Использование ИИ | Инструмент, цель, способ проверки результата или «не использовался» |
