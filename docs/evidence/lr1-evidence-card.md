# Evidence card ЛР1 — шаблон

Каждый участник копирует этот файл в `docs/evidence/lr1-evidence-card-<github-login>.md`
и заполняет его своими данными после создания tag `lr1-v1`. Совпадающие карточки не принимаются.
Все ссылки должны открываться и соответствовать истории GitHub.

| Поле | Значение |
|---|---|
| Студент | ФИО, учебная группа, команда №4, GitHub login |
| Контрольная версия | Ссылка на tag `lr1-v1` и commit SHA |
| Роль | Роль в ЛР1 и зона ответственности |
| Задача | Ссылка на собственную issue с критериями приемки |
| Личный артефакт | PR, review, workflow, README, CONTRIBUTING, CODEOWNERS, ADR или настройка правил |
| Вклад | Конкретное созданное, исправленное или проверенное изменение |
| Решение | Выбранный вариант и проверяемая причина выбора |
| Риск | Что могло пойти неверно и как это обнаруживается |
| Результат обучения | Что участник теперь может повторить самостоятельно |
| Использование ИИ | Инструмент, цель, способ проверки результата или отметка об отсутствии использования |
