## Как сдавать работы на курсе

каждый тимлид делает форк своей ветки от репозитория преподавателя. В своем форке тимлид создает отдельную ветку для каждого члена команды. Каждый участник команды делает форк своей ветки из репозитория тимлида и работает в ветке main в своем собственном репозитории. тимлид работает в ветке main своего репозитория. По завершении работы каждый участник сдает результат своего этапа в ЛР в виде PR в свою ветку темлида (затем эта ссылка прикрепляется в его ЛК на ДО.СКИФ в соответствующей ЛР - на каждом этапе). 

* лабораторная 1:

член команды выполнил работу -> сделал Pull Request из своего репозитория в свою ветку репозитория тимлида. в системе skif нужно прикрепить ссылку на этот самый PR.
тимлид работает в своей ветке main -> одобряет PR из репозиториев сокомандников в их ветки -> создает и одобряет PR из их веток в свою ветку main -> делает PR своей готовой ветки main в ветку своей команды в репозитории преподавателя. в системе skif нужно прикрепить ссылку на PR в репозиторий преподавателя.

* лабораторные 2-13:

член команды выполнил работу -> сделал Pull Request из своего репозитория в свою ветку репозитория тимлида. в системе skif нужно прикрепить ссылку на этот самый PR.
тимлид работает в своей ветке main -> одобряет PR из репозиториев сокомандников в их ветки -> создает и одобряет PR из их веток в свою ветку main. в системе skif нужно прикрепить ссылку на ветку main своего репозитория.

* финальная сдача:

член команды выполнил работу -> сделал Pull Request из своего репозитория в свою ветку репозитория тимлида. в системе skif нужно прикрепить ссылку на этот самый PR.
тимлид работает в своей ветке main -> одобряет PR из репозиториев сокомандников в их ветки -> создает и одобряет PR из их веток в свою ветку main -> делает PR своей готовой ветки main в ветку своей команды в репозитории преподавателя. в системе skif нужно прикрепить ссылку на PR в репозиторий преподавателя.
