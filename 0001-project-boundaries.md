# ADR 0001: Границы проекта

- **Статус:** Предложено
- **Дата:** 2026-11-03
- **Решение принимают:** команда Team 5

## Контекст
Для лабораторной работы требуется минимальный, воспроизводимый Python-проект с проверками качества и тестами в CI.

## Решение
- Используем Python 3.12.
- Зависимости и настройки инструментов фиксируем в `pyproject.toml`.
- Исходный код размещаем в `src/team5_mlops/`.
- Тесты размещаем в `tests/`.
- Ruff используем для linting; pytest — для тестирования.
- CI запускает проверки при push и pull request.

## Последствия
- Окружение проще воспроизвести на другой машине.
- Изменения проходят автоматические проверки.
- Дополнительные зависимости и архитектурные решения оформляем отдельными ADR при необходимости.
